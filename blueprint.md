# Blueprint Proyek

## Ringkasan

Proyek ini adalah aplikasi Flutter untuk manajemen keuangan pribadi, dengan fitur-fitur seperti:

*   **Manajemen Transaksi:** Mencatat pemasukan, pengeluaran, dan transfer.
*   **Manajemen Pelanggan:** Mengelola data pelanggan.
*   **Manajemen Paket:** Mengelola paket-paket layanan.
*   **Sinkronisasi Data:** Sinkronisasi data antara perangkat lokal dan Firebase.

## Arsitektur

*   **Manajemen State:** Provider
*   **Database Lokal:** SQLite
*   **Database Jarak Jauh:** Firebase Firestore
*   **Struktur Folder:** Berorientasi fitur (feature-oriented)

## Fitur yang Telah Diimplementasikan

*   **Struktur Proyek Awal:** Inisialisasi proyek Flutter dan pembuatan struktur direktori.
*   **Model Data:** Pembuatan model data untuk semua entitas dalam aplikasi.
*   **Enum:** Pembuatan enum untuk merepresentasikan tipe data yang telah ditentukan.
